# SpeechEQ

Приложение для автоматического улучшения качества и разборчивости речи в видеозаписях. Обработка выполняется полностью локально без передачи данных в облако.

## Возможности

- **DSP-методы**: шумоподавление, удаление гула 50/60 Гц, де-эссер, речевой эквалайзер, нормализация громкости по стандарту EBU R128
- **ML-модели**: FRCRN\_SE\_16K, MossFormerGAN\_SE\_16K, DeepFilterNet, MetricGAN+ *(экспериментальный)*
- **Два режима работы**: локальный (обработка внутри клиента, без сети) и удалённый (gRPC-сервер на отдельной машине)
- **Пакетная обработка** видео MP4/MOV/MKV с сохранением исходного видеоряда (ремультиплексирование через FFmpeg)

## Системные требования

- Python 3.10+
- FFmpeg (в PATH)
- ОЗУ: минимум 8 ГБ, рекомендуется 16 ГБ
- Место на диске: ~10 ГБ

## Установка

### Linux / macOS

```bash
chmod +x install.sh
./install.sh
```

### Windows

```bat
install.bat
```

Скрипты создают виртуальное окружение `venv` и устанавливают все зависимости из `requirements.txt`.

## Запуск

```bash
# Linux / macOS
./run_app.sh

# Windows
run_app.bat
```

В приложении два режима работы:

**Локальный режим** — обработка выполняется напрямую внутри процесса клиента, без gRPC и без отдельного сервера. Нажмите «Запустить локальный режим» в экране «Подключение».

**Удалённый сервер** — клиент подключается по gRPC к серверу, запущенному отдельно (на той же или другой машине):

```bash
# Linux / macOS
./run_server.sh

# Windows
run_server.bat
```

Затем в клиенте выберите «Удалённый сервер», укажите хост и порт и нажмите «Подключиться».

## Утилиты

### benchmark_processing.py

Измеряет скорость каждого метода обработки на синтетическом сигнале. Выводит время (мс) и RTF (Real-Time Factor — отношение времени обработки к длине аудио; RTF < 1 означает быстрее реального времени).

```bash
python benchmark_processing.py                 # 5 с аудио, 3 прогона
python benchmark_processing.py --duration 30   # 30-секундный клип
python benchmark_processing.py --skip-ml       # только DSP
```

**Результаты (CPU, без CUDA, аудио 30 с):**


DSP-методы работают в реальном времени на любом CPU. ML-модели на CPU медленнее реального времени (RTF > 1) — для них рекомендуется GPU.

### evaluate_models.py

Прогоняет ML-модели на парах чистый/зашумлённый аудио и считает объективные метрики: PESQ (качество речи), STOI (разборчивость), SI-SDR (отношение сигнал/шум).

```bash
python evaluate_models.py                            # папка examples/ по умолчанию
python evaluate_models.py --scp examples/pairs.scp  # по .scp-файлу
python evaluate_models.py --models frcrn mossformer  # выбор моделей
```

### compare_finetune.py

Сравнивает pretrain и finetune веса для MossFormerGAN или FRCRN на произвольном наборе пар.

```bash
python compare_finetune.py \
    --network mossformer \
    --scp examples/pairs.scp \
    --pretrain src/processing/ml/models/MossFormerGAN_SE_16K.pt \
    --finetune  /path/to/finetuned.pt
```

## Результаты оценки

### Метрики на тестовом наборе examples/

7 пар русской речи, 16 кГц, моно. Данные **намеренно сильно зашумлены** (SNR ≈ 5–6 дБ) для выявления разницы между моделями.

```
─────────────────────────────────────────────────────────────────────────────────────────
Модель            PESQ до  после      Δ  STOI до  после      Δ  SI-SDR до   после       Δ
─────────────────────────────────────────────────────────────────────────────────────────
Noisy (baseline)     1.25      —      —    0.882      —      —       5.83       —       —
FRCRN_SE_16K         1.25   3.39  +2.13    0.882  0.982 +0.100       5.83   19.01  +13.18
MossFormerGAN        1.25   3.64  +2.39    0.882  0.983 +0.101       5.83   21.41  +15.58
MetricGAN+           1.25   1.52  +0.27    0.882  0.853 -0.029       5.83    2.34   -3.49
DeepFilterNet        1.25   2.16  +0.91    0.882  0.914 +0.032       5.83   14.71   +8.88
─────────────────────────────────────────────────────────────────────────────────────────
```

MossFormerGAN и FRCRN_SE_16K показывют хорошие результаты по всем трём метрикам. MetricGAN+ плохо справляется с сильно зашумлёнными данными и в целом уступает остальным моделям — в интерфейсе он помечен как экспериментальный.

### Эффект дообучения FRCRN на русских данных

Дообучение на 25 000 пар русскоязычных аудиозаписей. Тестовый набор — отложенная выборка из того же распределения.

| Состояние | PESQ | STOI | SI-SDR |
|---|---|---|---|
| Зашумлённый (baseline) | 1.870 | 0.906 | 13.58 |
| FRCRN pretrain | 3.025 | 0.963 | 19.26 |
| FRCRN finetune | 3.193 | 0.968 | 20.22 |
| **Δ (finetune − pretrain)** | **+0.168** | **+0.005** | **+0.96** |

Дообучение даёт стабильный прирост по всем метрикам при относительно небольшом датасете.

## Структура репозитория

```
SpeechEQ/
├── src/
│   ├── client/          # GUI (PySide6), gRPC-клиент
│   ├── server/          # gRPC-сервер, pipeline обработки
│   ├── proto/           # .proto-файлы и сгенерированный gRPC-код
│   └── processing/
│       ├── dsp/         # DSP-методы (шумоподавление, EQ и др.)
│       └── ml/          # ML-модели и базовые классы
│           └── models/  # веса моделей (Git LFS)
├── examples/
│   ├── clean/           # эталонные WAV-файлы
│   ├── noisy/           # зашумлённые WAV-файлы
│   └── pairs.scp        # список пар для evaluate/compare
├── evaluate_models.py   # оценка качества моделей
├── compare_finetune.py  # сравнение pretrain vs finetune
├── benchmark_processing.py  # замер скорости
├── requirements.txt
├── install.sh / install.bat
└── run_app.sh / run_app.bat
```
